# Análisis de la calidad del aire en el Área Metropolitana de Monterrey

## Descripción

Este proyecto tiene como objetivo analizar datos históricos de
calidad del aire registrados por estaciones de monitoreo del
estado de Nuevo León.

## Objetivo

Analizar las concentraciones de contaminantes atmosféricos y
estudiar su comportamiento entre las diferentes estaciones de
monitoreo y a través del tiempo.

## Contaminantes de interés

- PM2.5
- PM10
- O3
- NO2
- SO2
- CO

## Fuente de datos

Los datos utilizados en este proyecto provienen de registros
oficiales de calidad del aire de Nuevo León.

## Herramientas

- Python
- Git
- GitHub
- LaTeX

## Estructura del proyecto

- `data/`: datos utilizados en el análisis.
- `src/`: código fuente en Python.
- `docs/`: documentación del proyecto.
- `results/`: gráficas y resultados del análisis.
